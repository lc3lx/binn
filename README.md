# binn

Full-stack project with a Next.js frontend and an Express/MongoDB backend.

- `frontend/`: web application
- `backend/`: API and background workers
- `nginx.conf`: Nginx configuration

Install dependencies with `npm ci` inside each application directory.
Configure local environment variables before starting the applications.

Run the backend with `npm run start:dev` and the frontend with `npm run dev`
from their respective directories.

Environment files, uploaded user files, dependencies, and local backups are
excluded from version control.
